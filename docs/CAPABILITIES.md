# 产品能力与本仓库演示

| 主题 | 产品说明 | 本仓库可运行内容 |
| --- | --- | --- |
| 通知 | 经权限授权接收 Android 通知和配对 iPhone 共享通知，保存到 Android 本地 | 虚构通知筛选与来源详情 |
| WITH 会话 | 个人 Agent 交流入口 | 固定规则回复、浏览器保存会话 |
| WITH 记忆 | 用户可理解的个人信息与偏好 | 手动确认、编辑、删除示例记忆 |
| 健康追踪 | 健康记录与变化展示 | 固定虚构指标及趋势 |
| 餐饮 | 餐食记录与热量信息 | 手动输入与汇总、临时照片预览 |

“开源”指这个仓库明确提供的设计实现与文档；功能介绍不意味着全部产品实现已经包含在仓库。

## 验证方法

运行 npm run check 后启动原型。依次检查：通知筛选与详情；新增、编辑、删除记忆；WITH 引用最新记忆；新增和删除餐食后汇总更新；刷新后文字记录保留；导出和重置；手机宽度下无横向溢出。

照片仅本页预览。真实权限、设备连接、通知完整性、模型行为和长期运行不属于这个原型的验证结果。
