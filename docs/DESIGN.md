# 公开设计说明

## 定位

CYBONE 是个人数字分身。公开设计围绕用户能够回看、理解和管理的日常信息展开。

## 五个页面

| 页面 | 交互 | 设计重点 |
| --- | --- | --- |
| TODAY | 来源筛选、原文查看、进入会话 | 信息来源可辨认 |
| WITH | 发送文本、示例问题、历史展示 | 区分用户输入与模拟回复 |
| 记忆 | 确认新增、编辑、确认删除 | 用户能看见和管理记忆 |
| 健康 | 指标与七日趋势展示 | 时间与单位清晰 |
| 餐饮 | 输入餐次、记录、照片预览、删除 | 区分输入值、合计与估算 |

## 组件与样式

styles.css 提供统一变量：背景、表面、文本、次要文本、分隔线、薄荷绿强调色和圆角。可复用类包括 .row、.segmented、.metric-large、.message、.stack、.primary 和 .secondary。

界面使用系统字体，优先保留中文可读性。窄屏纵向排布；浅色模式跟随系统。导航有当前页面标记，表单具有标签，弹窗使用原生 dialog，动态操作结果通过状态区域播报。没有必须依赖动画理解的内容。

## 状态与数据

model.js 管理虚构样本、存储校验、热量合计、规则回复及文本转义。app.js 管理页面与交互。界面输入进入 HTML 前转义；存储损坏时恢复样本；存储写入失败时提示临时保存边界。

示例日期固定，以保持展示一致。这个设计原型没有真实通知采集、真实模型推理或自动营养分析。
